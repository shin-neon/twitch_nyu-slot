# にゅスロット v2

GitHub Pages でそのまま公開できる、HTML/CSS/JavaScript 製の無料ブラウザゲームです。外部ライブラリ、サーバー、ビルドは不要です。

## 公開手順

1. GitHub で公開用リポジトリを作成します。
2. このフォルダの **中身**（`index.html`、`style.css`、`script.js`、`assets/`）をリポジトリのルートにアップロードします。
3. GitHub リポジトリの **Settings → Pages → Build and deployment** で `Deploy from a branch` を選び、`main` / `/(root)` を指定して保存します。
4. 数分後に表示される Pages URL にアクセスします。

ローカルで試す場合は `index.html` を開いてください。ブラウザの制限により file:// での LocalStorage は安定しない場合があるため、公開先の GitHub Pages での利用を推奨します。

## ゲーム仕様

- 初期メダル **100枚**、1ゲーム **3枚BET**。
- 通常ゲーム開始時に内部抽選：BIG **1/140**、REG **1/280**（合算約 **1/93.3**）。
- 当選ゲームの全リール停止後、添付画像のランプが点灯します。
- 成立したボーナスは保存され、**次ゲーム**でBIG `7️⃣×3` / REG `⭐×3` が中央ラインに停止し、BIG **240枚** / REG **96枚** を払い出します。
- 通常ゲームの小役：`🍇×3` 8枚、`🔔×3` 10枚、左中央 `🍒` 2枚。ボーナス成立ゲームは小役なし。
- リールは押し順自由。STOPのタイミングで当選結果は変わりません。
- メダル・BET・ボーナス成立状態・ゲーム数・当選回数は `localStorage` に自動保存。ページ更新中のリール演出は復元しません（ゲーム開始後に更新した場合、そのゲームのBETは消費されます）。
- 記録を初期化するボタンがあります。ブラウザのサイトデータ削除・シークレットモード・別ブラウザ間では記録は共有されません。
- キーボード：`B` = BET、`Space` / `Enter` = START、`1` / `2` / `3` = STOP。

**注意**：実機のリール制御・配当・演出を再現するものではありません。課金・換金・景品交換はありません。添付画像の利用権については公開者自身で確認してください。
